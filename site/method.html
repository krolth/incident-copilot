How it works

Three ways to triage the same alert

All three designs get the same alert, the same four tools over the same data, and must return the same typed answer. Only the control flow differs: who decides what to look at, and how many models are involved.

The evaluation

From incident to score

Every incident is generated by code from a fixed seed, so all runs see identical logs and metrics. The ground truth is written down before any model runs and frozen once real results exist.

The 18 incidents

Each has a trap

Easy incidents have none: the obvious reading is right. Medium ones add one natural coincidence. Hard ones misdirect, or have no single answer. Prompts were tuned on the three dev incidents only.
