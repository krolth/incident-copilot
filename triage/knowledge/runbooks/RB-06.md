---
id: RB-06
title: Rotate an expired certificate or credential
category: expired_credential
---
## When to use
Connections fail authentication or TLS handshakes starting at an exact moment, and the failure is on the connection itself rather than in load or code.

## Signals
- Log lines such as "certificate has expired", "handshake failure", "401 unauthorized: token expired".
- The failures begin at a precise timestamp that matches a certificate or token expiry.
- CPU, memory, and traffic look normal; errors are close to 100 percent for the affected path and zero elsewhere.
- Recent deploys are unrelated: an expiry fails the same way regardless of code changes.

## Steps
1. Read the expiry time from the certificate or token metadata and confirm it matches the failure start.
2. Issue and install a renewed certificate or credential on the server side that owns it.
3. Reload or restart only the components that cache the old credential.
4. Verify handshakes succeed; add monitoring for upcoming expiries.

## Do not
Roll back deploys or scale out; neither changes an expired credential.
