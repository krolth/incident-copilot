---
id: RB-06
title: Renew an expired certificate or credential
category: expired_credential
---
## When to use
Connections fail TLS handshakes or authentication from one exact moment on, for one path, while load, code and
hosts look normal. Mitigate by installing a valid certificate or credential.

## What expires on Fianchetto
| Item | Breaks | Renewal |
|---|---|---|
| `api.fianchetto.example` cert | every API call through the gateway | automatic (ACME); check the renewal job if it expired |
| `*.play.fianchetto.example` wildcard cert | every game connection to every game-server host; the API keeps working | manual, copied to each gs host |
| JWT signing key | all authenticated API calls (gateway rejects tokens) | every 90 days; gateway must have the new public key first |
| identity provider client secret | social login only | yearly, manual |

## Signals
- Logs such as "certificate has expired", "tls: handshake failure", "x509: certificate has expired or is not yet
  valid", "401 invalid token signature", "invalid_client".
- Failures start at a precise timestamp that matches the expiry time, are close to 100% on the affected path, and
  zero elsewhere.
- CPU, memory and traffic normal; the alert may show as a drop in games started or a spike in client reconnects.

## Steps
1. Read the expiry from the certificate or credential (`openssl s_client -connect <host>:443 | openssl x509 -noout -enddate`)
   and confirm it matches the start of the failures.
2. Issue or fetch the renewed certificate or credential.
3. Install it where it is served: for the wildcard cert, on every game-server host; reload the TLS listener
   (live reload, no restart, so running games stay up). For a JWT key, roll out the new public key to the gateway
   before accounts signs with the new key.
4. Verify handshakes succeed from outside, then add expiry monitoring for that item.

## Do not
- Roll back deploys or scale out: neither changes an expired credential.
- Restart game-server hosts to pick up the certificate: reload the listener instead.
